# Athena Bhuto | Portfolio

Personal portfolio site for Athena Bhuto: M.Tech (CSE, Cybersecurity) at CUSAT, B.Tech in Information Technology.

Built with plain HTML, CSS and JavaScript. No build step and no dependencies.

## Run locally

Open `index.html` in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Customise

- Content lives in `index.html`.
- Colours and fonts are defined at the top of `style.css`.
- GitHub and project links are set in the `CONFIG` object at the top of `script.js`. Empty values are hidden automatically.

## Deploy

Hosted on GitHub Pages from the `main` branch: https://athenabhuto-git.github.io/portfolio/
